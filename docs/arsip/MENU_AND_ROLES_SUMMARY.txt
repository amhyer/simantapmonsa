🔒 SECURITY MIDDLEWARE
═══════════════════════════════════════════════════════════════════════════════

Applied to ALL authenticated routes:
  • auth (verify user logged in)
  • role:admin|guru|siswa|ortu|kepsek (verify user role)
  • force.password.change (block until password changed if required)

Rate Limiting:
  • Login: throttle:10,1 (10 per minute)
  • Register: throttle:5,1 (5 per minute)
  • Data operations: throttle:30-60,1
