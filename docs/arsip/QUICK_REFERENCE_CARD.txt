┃ = Integrated Academic Management Information System                        ┃
┃                                                                             ┃
┃ For Indonesian K-12 Schools (SD / SMP / SMA)                               ┃
┃                                                                             ┃
┃ Manages: Students | Grades | Materials | Quizzes | Attendance            ┃
┃          Report Cards | Habits | Co-curricular | Integration              ┃
┃                                                                             ┃
┗━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┛

┃ 👥 THE 5 ROLES                                                             ┃
┣━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┫
┃                                                                             ┃
┃ 1️⃣  ADMIN (👨‍💼 System Admin)                                              ┃
┃     • Full system control                                                  ┃
┃     • Create/delete users (bulk)                                           ┃
┃     • Manage school settings                                               ┃
┃     • Import from Dapodik                                                  ┃
┃     • Backup/restore database                                              ┃
┃     → URL: /admin                                                           ┃
┃     → Users: IT staff, system managers                                      ┃
┃                                                                             ┃
┃ 2️⃣  GURU (👨‍🏫 Teacher)                                                     ┃
┃     • Input student grades                                                 ┃
┃     • Upload teaching materials                                            ┃
┃     • Create & manage quizzes                                              ┃
┃     • Record attendance                                                    ┃
┃     • Generate report cards (e-Rapor)                                      ┃
┃     → URL: /guru                                                            ┃
┃     → Users: Teachers, instructors                                         ┃
┃                                                                             ┃
┃ 3️⃣  SISWA (👨‍🎓 Student)                                                    ┃
┃     • Access learning materials                                            ┃
┃     • Take quizzes                                                         ┃
┃     • View grades                                                          ┃
┃     • Check attendance                                                     ┃
┃     • Update personal profile                                              ┃
┃     → URL: /siswa                                                           ┃
┃     → Users: K-12 students                                                 ┃
┃                                                                             ┃
┃ 4️⃣  ORTU (👨‍👩‍👧 Parent)                                                    ┃
┃     • Monitor child's grades                                               ┃
┃     • View attendance & notes                                              ┃
┃     • Submit habit tracking (7 Kebiasaan)                                  ┃
┃     • Download report card (e-Rapor)                                       ┃
┃     • Multi-child support                                                  ┃
┃     → URL: /ortu                                                            ┃
┃     → Users: Parents, guardians, wali                                      ┃
┃                                                                             ┃
┃ 5️⃣  KEPSEK (🎓 Principal)                                                  ┃
┃     • Monitor all teachers & students (read-only)                          ┃
┃     • Real-time progress dashboard                                         ┃
┃     • View aggregated analytics                                            ┃
┃     • Export compliance reports                                            ┃
┃     • School-wide oversight                                                ┃
┃     → URL: /kepsek                                                          ┃
┃     → Users: Principal, vice-principal                                     ┃
┃                                                                             ┃

┃ ─────────────────────────────────────────────────────────────────────      ┃

┃ WORKFLOW 3: Student Learning                                              ┃
┃ ─────────────────────────────────────────────────────────────────────      ┃
┃ Siswa → Access Materi → Study → Take Kuis → View Nilai                    ┃

┃ WORKFLOW 4: Admin Importing Data                                           ┃
┃ ─────────────────────────────────────────────────────────────────────      ┃
┃ Admin → Dapodik → Upload CSV → Preview → Import                           ┃
┃      → Check log → Data ready for class assignment                        ┃
┃                                                                             ┃
┃ WORKFLOW 5: Principal Generating Report                                    ┃
